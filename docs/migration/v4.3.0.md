# v4.3.0 迁移手册

> 适用：从 v4.2.x 升级到 v4.3.0（改善案例与证据账本）。升级前请备份
> 重要 `.qap` 项目与 `user_config.json`；本版本所有迁移均为**增量兼容**，
> 不删除旧数据。

## 1. 兼容矩阵

| 对象 | 旧格式 | v4.3.0 行为 |
|------|--------|-------------|
| `.qap` 1.6 / 1.7 | 无凭证段 | 可读；视为无凭证（复核面板显示「不可比较」） |
| `.qap` 1.8 | 有凭证段 | 可读；首次保存自动升级为 1.9 |
| `.qap` 1.9 | 标准 / 测量 / 证据段 | 读写完整支持 |
| 案例 schema v0 | 仅 id/title/steps 等 | 打开时自动升级为 v1（默认值补齐，steps 不丢）；再次保存写回 v1 |
| 插件 API 2.0 | tab / agent_tools / settings | 完全兼容，不受影响 |
| 插件 API 2.1 | 新增 `data_source` 能力 | 按需声明；未声明则不会被调用 |
| 无时区时间戳 | 历史数据 | 读取时按本机时区（默认 Asia/Shanghai）解释；新写入一律带时区偏移 |

> 反向兼容：v4.2.x 仍可打开 1.9 项目（忽略 standards / measurements / evidence
> 三个新段），但看不到标准历史与证据链。回退前建议保留升级前的 `.qap` 副本。

## 2. 升级步骤

1. **备份**：复制需要保留的 `.qap`、`user_config.json`（如使用密钥环，无需迁移密钥）。
2. **替换程序**：使用 v4.3.0 源码 / 安装包启动；`python tools/check_version.py` 应通过。
3. **打开旧项目**：首次打开 1.6–1.8 项目时，软件会：
   - 从 `QualityCharacteristic` 的 USL/LSL/Target 迁移出首版 `spec_limit` 标准记录
     （`origin=migration`，变更原因「历史数据迁移」）；
   - 案例 schema v0 自动补齐 v1 字段；
   - 证据账本与测量事件从空账本开始（旧项目没有这些数据）。
4. **另存一次**：保存后项目升级为 `.qap` 1.9，新增
   `standards.json`、`measurements.jsonl`、`evidence/events.jsonl`。
5. **验证**：菜单「工具 → 标准版本记录」应能看到迁移出的规格限；
   「工具 → 证据视图」应显示账本链校验通过（空账本也视为通过）。

## 3. 插件迁移（可选）

数据源插件（如视觉）升级到 API 2.1：

```json
{
  "id": "your_source",
  "api_version": "2.1",
  "capabilities": ["data_source"]
}
```

```python
def provide_measurements(self, context=None):
    # 返回 MeasurementEvent 列表；空列表表示本轮无数据
    return [MeasurementEvent.from_dataframe(df, channel="cycle",
                                            method="vision-cycle")]
```

- 未声明 `data_source` 的 2.0 插件零改动；
- 主程序强制事件来源为 `plugin/<插件 id>`，并隔离超时 / 坏数据 / 未信任调用；
- 持续采集可用 `host.submit_measurements(events, plugin_id=...)` 异步注入；
- 详细合同见 [`docs/plugin-data-source.md`](../plugin-data-source.md)。

## 4. 时间语义与证据链

- 新事件时间戳一律 ISO-8601 带偏移（默认 Asia/Shanghai）；设备 epoch 原样保留；
- 历史无时区时间按本机时区解释，不静默改写；
- 证据账本为 append-only 哈希链：手动编辑 `evidence/events.jsonl` 会导致链校验失败，
  证据视图会定位到首个断点。篡改检测 ≠ 防篡改，请通过只读权限 / 备份保护原始文件。

## 5. 图形依赖（可选）

自 v4.3.0 起 matplotlib / seaborn 不再阻塞启动：

- 未安装时主界面、数据导入、分析引擎、案例与证据功能均可使用；
- 打开图表类 Tab 会提示安装：`pip install matplotlib seaborn`；
- 建议仍按 `requirements.txt` 安装完整依赖以获得全部图表能力。

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| 旧项目打开后「标准版本记录」已有记录 | 这是自动迁移的首版规格限，可直接在其上保存新版本 |
| 证据视图提示「不可复核」 | 该结论产生于 1.7 及更早版本（无凭证），重跑一次分析即可生成 |
| 证据包校验失败 | 文件被修改或缺失；用「泄漏扫描 / 独立校验」定位具体文件 |
| 脱敏分享包扫描告警 | 检查导出内容是否包含原始表 / 列名或禁用词；v1 只输出合成数据 |
| 案例无法关闭 | 需先完成复测并给出带凭证的统计判定，并填写关闭原因 |
