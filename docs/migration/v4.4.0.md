# v4.4.0 迁移手册

> 适用：从 v4.3.x 升级到 v4.4.0（闭环执行与效果验证）。升级前请备份重要
> `.qap` 项目与 `user_config.json`；本版本所有迁移均为**增量兼容**，
> 不删除旧数据。**注意有一处修正性行为变更**（见 §3），抽样方案输出会变化。

## 1. 兼容矩阵

| 对象 | 旧格式 | v4.4.0 行为 |
|------|--------|-------------|
| `.qap` 1.6 / 1.7 / 1.8 | 无标准 / 测量 / 证据段 | 可读；对应段落按空处理 |
| `.qap` 1.9 | 标准 / 测量 / 证据段 | 可读；首次保存自动升级为 2.0 |
| `.qap` 2.0 | 新增 抽样 / 量具 / 收益 / 技能四段 | 读写完整支持 |
| 案例 schema v0 / v1 | id/title/steps… | 不变式兼容；新增可选字段 `evidence_required`（默认 False） |
| 证据事件 / 标准记录 / 测量事件 schema v1 | — | 不升级；仅事件类型枚举扩容（+7 类） |
| 插件 API 2.0 / 2.1 | tab / agent_tools / settings / data_source | 完全兼容，无破坏性改动 |
| 分阶段文档不迁移 | 旧版字段原样保留 | — |

> 反向兼容：v4.3.x 可打开 2.0 项目（忽略新四段），但看不到抽样状态的
> 持久化、量具在线状态、收益账本与技能矩阵。

## 2. 升级步骤

1. **备份**：复制需要保留的 `.qap` 与 `user_config.json`。
2. **替换程序**：使用 v4.4.0 源码 / AppImage 启动；`python tools/check_version.py` 应通过。
3. **打开旧项目**：1.6–1.9 项目首次保存自动升级为 `.qap` 2.0，新增
   `sampling.json` / `gauge_studies.json` / `benefits.json` / `skills.json`
   （无数据时按空处理，不写空段）。
4. **重建一次基线（可选）**：如需收益账本口径，请在案例关闭后于
   「登记收益」表单入账；收益记录会自动携带案例标准引用解析出的版本。
5. **验证**：菜单「工具 → 收益账本 / 标准版本记录 / 证据视图」应可正常打开；
   抽样 Tab 的「批检验（转移）」面板可查询方案。

## 3. 修正性行为变更（重要）

**AQL 抽样表全面纠正**：v4.3.x 及以前的正常检验表与 GB/T 2828.1 原表不符
（A~H 行数字格错位、J/K 行完全相同、箭头语义未实现、检验水平参数被忽略、
加严/放宽表缺失）。v4.4.0 以标准原表重建并经四重交叉验证，因此：

- AQL 查表与计量型抽样的**字码 / 样本量 / Ac / Re 输出会变化**（变为正确值）；
- 箭头（↓/↑）开始按标准语义解析：样本量可能取自相邻字码行；
- 旧记录中的抽样方案数据不自动改写；如需复判请重新查表并登记新版本。

其他变更：

- 控制计划逐格编辑改为**节流合并**（1.5 秒静默后落一个带原因的版本），
  批量导入 / 显式「保存标准版本」行为不变；
- SPC 多图分析（如 XBar-R 的均值图 + 极差图）控制限**全部**写入标准记录，
  子图对象引用为 `列:XBar-R:r_chart` 形式（主图引用保持向后兼容）。

## 4. 决策记录（PLAN_v4.4.0 §8 默认值落地）

| 决策 | 落地值 |
|------|--------|
| `.qap` 版本 | 2.0（1.6–1.9 只读兼容） |
| 告警自动立案阈值 | 仅 critical |
| 放宽检验（reduced） | 默认禁用，需显式启用（`SamplingStateManager(reduced_enabled=True)`） |
| 立案去重窗口 | 同规则 30 分钟，合并为同案步骤 |
| 技能矩阵编辑器 | 线平衡 Tab 内对话框（不新增 Tab） |
| 收益入账范围 | 案例关闭后登记（含手动补录）；C 级只登记不计入汇总 |
| `measurement_capture` | **维持默认关闭**：连接器常驻采集不写项目测量集合；案例按最近窗口显式采集。如需常开需先评估 FIFO 截断与账本增长的现场影响 |

## 5. 新功能速查（与老流程的差异）

| 功能 | 入口 | 要点 |
|------|------|------|
| 告警自动立案 8D | 自动（critical 告警） | 案例中心「来源」列显示"自动立案"；D6 门禁要求复测数据引用 |
| 测量系统在线 | MSA Tab「量具在线监控」 | 偏倚序列 MPC 图 ≥10 点预热；漂移提示 1 小时冷却；状态随 `.qap` 保留 |
| 可信抽样 | 抽样 Tab「批检验（转移）」 | 方案按当前状态查表；种子可复现；抽样决定入证据账本 |
| 收益账本 | 「工具 → 收益账本」/ 案例关闭后表单 | 月度复算：历史月冻结、当月口径前移；防重复键不含标准版本 |
| 技能约束线平衡 | 线平衡 Tab | 未录入技能 = 不具备（保守口径）；不可行输出明细 |

## 6. 常见问题

| 问题 | 处理 |
|------|------|
| 查表结果与旧版本不同 | 这是修正：旧表与标准原表不符（§3）；以新结果为准 |
| 加严/放宽状态如何复位 | 「批检验（转移）」面板手动覆盖（必须填原因，进证据账本） |
| 量具漂移提示太频繁 | 提示带 1 小时冷却；确需重做研究后状态随下一次测量刷新 |
| 收益复算把历史月改了 | 不会：历史月冻结仅出快照；当月复算只刷新标准口径标记，金额不变 |
| 技能排班总是不可行 | 检查工序最低等级要求与人员录入（未录入=不具备）；设备并发上限为并行求和口径 |
| v4.3.x 打开 2.0 项目会怎样 | 可打开，新四段被忽略；回退前请保留升级前副本 |
