## 要点

### 质量加固（P1–P5，2026-09-28）

- **P1 静态棘轮扩容**：11 条规则（RET505/506 · RUF010/RUF100 · SIM105/113/114/201 ·
  C408/416/420 · PERF102 · PLW0108 · PLW3301）清零入闸；修复 2 处死代码
  （`sampling_engine` 只写不读的 total、`smed_tab` 甘特 y 计数），100 文件清理
- **P2 静默失败治理**：审计写入失败计数 + warning；会话/调度/一键分析/配置迁移补日志；
  31 处 pass-only 异常全部带理由；**修复批量调度必然失败**（对话框未注入执行器 →
  新增无 Qt 默认执行器 `run_task_headless`，数据源→分析→docx/pdf/xlsx/Markdown 报告）
- **P3 数值鲁棒性**：新增 `analysis/_sanitize.py` + `spc/_validation.py`，±inf / 缺失值
  在分析入口统一净化，修复 6 类底层报错（指数平滑 No supported index · 计数四图
  NaN/inf 转换崩溃 · 残差图 Ljung-Box 空序列 IndexError · 能力六合图 range not finite）
- **P4 性能向量化**：Nelson 判异向量化（2100 项等价性对照 0 差异）→ **SPC 100 万点
  21.96s → 1.62s（13.5×）**；解析逐格回调向量化 → **百万行导入 14.27s → 5.19s（2.7×）**，
  `perf_baseline.json` 同步收紧锁定收益
- **P5 回归修复与收尾**：修复自动修复引入的 3 处语义回归；质量审查记录见
  [`docs/quality/2026-09-28-quality-review.md`](../quality/2026-09-28-quality-review.md)

### 品牌与体验（2026-10-01）

- **AKIA 更名收尾 + 迁移兼容层**：应用名 / 组织 / 配置路径 / keyring 服务名 / 插件入口组
  统一为 AKIA，旧数据一次性迁移（QSettings / 用户配置 / keyring 主密钥 / `.qamodel` /
  插件目录），保留「新名优先、旧名回退」，老用户升级零丢数据；新增 7 例迁移测试
- **新应用图标**：冷瓷白三层光影（外投影 / 瓷砖本体 / 字标），1024 / 256 / ICO 全尺寸；
  新增 `tools/generate_logo.py` 可复现生成
- **修复打包缺陷**：PyInstaller `--add-data` 目标写成同名文件名会被当成目录，导致冻结版
  `_internal/logo.png` 为目录、logo 与 `user_config.default.json` 静默丢失；目标改为 `.`
- **修复通用图表类型选择器**：原先内联展开会被配置列高度裁剪、图块挤压重叠；改为
  Qt.Popup 浮层下拉（三列固定 152×44 图块，点击外部 / Esc / 选中自动收起）
- **取消加载界面**：启动直接显示主界面；`scipy.stats` / `sqlalchemy` 延迟导入、
  图表字体与重依赖预热后置到首帧之后——冷启动基准 **2.10s → 1.06s**（端到端 3.3s → 1.35s）
