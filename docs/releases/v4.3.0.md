## 关键能力

- **案例即脊柱**：基线 → 时间研究 → 线平衡 → 改善 → 复测 → 配对检验 → 结论 → 标准，
  每步带时间戳、数据引用、测量事件与判定凭证；关闭必须由复测 + 统计判定放行。
- **标准可复判**：任意历史批次可还原当时生效的规格限 / 控制限 / 标准工时；
  报告追溯码随标准版本变化。
- **证据可验证**：所有关键动作进入 append-only 哈希链；证据包逐文件哈希 + 链校验，
  可在不加载主程序的前提下独立验证；脱敏分享包只含参数化合成数据与等价声明。
- **启动更稳**：matplotlib / seaborn 缺失不再阻塞主界面，非图表 Tab 照常可用；
  图表 Tab 显示可执行的安装指引而非异常堆栈；解释器缺核心依赖（PySide6 / numpy / pandas）
  时主入口给出明确提示与退出码，不再裸抛 `ModuleNotFoundError`。

## 已知限制

- 脱敏分享包 v1 对数值列使用正态参数化合成；强非正态 / 多峰数据的等价声明可能偏保守，
  后续版本评估 Johnson / 分位数映射（需先做隐私评审）。
- 连接器常驻采集默认不写项目测量集合（避免长时运行撑大 `.qap`），案例按最近窗口显式采集。
- MeasurementStore 默认上限 2000 条（FIFO）；需要长期留存的现场应按批次归档证据包。
- Windows 安装包需在 Windows 侧构建（`build_pyinstaller.py` + `packaging/AKIA-installer.iss`）。
