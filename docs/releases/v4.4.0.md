## 关键能力

- **异常即立案**：critical 告警发生秒级生成 8D 草稿（快照、违规点、特性、FMEA 条目），
  案例关闭必须关联复测数据与统计判定（配对 / SPC / 能力），纯文字结论不被接受。
- **测量不是一次性研究**：标准件与重复测量持续积累，滚动重复性 / 偏倚接入 MPC 判异，
  漂移超限时账本 + 告警中心 + 状态栏同步提示。
- **抽样可信**：转移规则确定性执行（同参数重跑样本逐行一致）；任一检验批可还原方案依据；
  抽样决定（方法 / 种子 / AQL / 样本量 / 行指纹）随证据包独立校验；手动覆盖必填原因。
- **收益可算**：月度复算口径与标准版本一致、金额不因版本改数；低可信数据被置信门禁拦截；
  直接回答「这条改善省了多少」。
- **排班可执行**：技能约束下输出可现场执行的排班与不可行明细清单（技能不满足 / 无人可用 /
  人数不足 / 设备并发），而不是只给一个理论平衡率。
- **抽样透明**：展示 / 分析层不存在未标注的抽样——图表 300 点、趋势 1000 点、画像大表
  正态检验的统一抽样决定记录与界面说明。

## 升级与兼容

- `.qap` 2.0：新增 `sampling.json` / `gauge_studies.json` / `benefits.json` / `skills.json`
  四段；1.6–1.9 旧文件可读并首次保存自动升级；v4.3.x 打开 2.0 项目会忽略新四段。
- 案例 schema v0 / v1 不变式兼容；证据事件 / 标准记录 / 测量事件 schema v1 不升级；
  插件 API 2.0 / 2.1 完全兼容。
- **修正性行为变更（重要）**：AQL 查表与计量型抽样的字码 / 样本量 / Ac / Re 输出变为
  标准正确值；箭头（↓/↑）开始按标准语义解析；控制计划逐格编辑改为 1.5s 节流合并落版；
  SPC 多图分析子图控制限对象引用新增 `列:XBar-R:r_chart` 形式（主图引用向后兼容）。
- 迁移细节见 [`docs/migration/v4.4.0.md`](../migration/v4.4.0.md)。

## 已知限制

- 脱敏分享包 v1 对数值列使用正态参数化合成；强非正态 / 多峰数据的等价声明可能偏保守
  （后续版本评估 Johnson / 分位数映射，需先做隐私评审）。
- 连接器常驻采集默认不写项目测量集合（`measurement_capture=False`，避免长时运行撑大
  `.qap` 与账本）；案例按最近窗口显式采集。
- MeasurementStore 默认上限 2000 条（FIFO）；需要长期留存的现场应按批次归档证据包。
- 大样本（>5000 行）正态检验使用固定种子 42 抽样（可复现，非全量检验）。
- 放宽检验（reduced）默认禁用，需显式启用（`SamplingStateManager(reduced_enabled=True)`）。
- Windows 安装包需在 Windows 侧构建（`build_pyinstaller.py` + `packaging/AKIA-installer.iss`）。
