  非正态能力 Bootstrap 区间、Weibull/ALT 可靠性区间修正、ARIMA 自动选阶稳健性

  报告页脚 12 位追溯码；同数据重跑自动逐项 diff；guide.html 新增「方法与参考」
- **闭环切片**：改善案例工作台（工具菜单）以 8 阶段脊柱串联基线 → 时间研究 → 线平衡 →
  改善 → 复测 → 配对检验 → 结论 → 标准草稿，每步留痕时间戳/数据引用/凭证
- **稳定性**：性能基准扩至 8 项（含 SPC 10 万/100 万行）；22 例退化输入契约；
  `BLE001` 盲除异常门禁自算法层启用；新增逐文件测试运行器 `tools/run_tests.py`

  mewma / gen_var / residual）
