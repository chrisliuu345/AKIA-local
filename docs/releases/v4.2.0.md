# v4.2.0 发布说明（源码 prerelease）

## 交付物

- GitHub Source zip / tar.gz（tag `v4.2.0`，标记 **pre-release**）
- 不打安装包；Linux 如需打包仅出 AppImage（`build_appimage.sh`），Windows 安装包在
  Windows 侧由 `packaging/QA-Tool-installer.iss` 构建

## 要点

- **算法可信**：已知值矩阵 29 例 + 算法深度 60 例 —— MEWMA（Lowry 1992，逐点精确
  Σ_Z(i)）、广义方差 |S| 图、PELT 变点检测（与暴力 DP 全局最优一致）、ARIMA 残差控制图、
  非正态能力 Bootstrap 区间、Weibull/ALT 可靠性区间修正、ARIMA 自动选阶稳健性
- **可追溯**：判定凭证（规则版本 + 参数 + 数据指纹 + 软件版本）写入分析记录与 `.qap` 1.8；
  报告页脚 12 位追溯码；同数据重跑自动逐项 diff；guide.html 新增「方法与参考」
- **闭环切片**：改善案例工作台（工具菜单）以 8 阶段脊柱串联基线 → 时间研究 → 线平衡 →
  改善 → 复测 → 配对检验 → 结论 → 标准草稿，每步留痕时间戳/数据引用/凭证
- **稳定性**：性能基准扩至 8 项（含 SPC 10 万/100 万行）；22 例退化输入契约；
  `BLE001` 盲除异常门禁自算法层启用；新增逐文件测试运行器 `tools/run_tests.py`
- **工具**：QAM Harness 本地工具 36 → 37（新增 `detect_changepoints`，`run_spc` 支持
  mewma / gen_var / residual）
