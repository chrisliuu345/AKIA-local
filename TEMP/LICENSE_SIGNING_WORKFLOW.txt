# QA-Tool License 签发流程

## 1. 首次生成密钥对

    python tools/license_generator.py --genkey

生成文件：
- ~/.qa_tool/license_key.pem — Ed25519 私钥（保密！）
- 公钥自动更新到 core/license_keys.py

## 2. 在目标机器获取 machine_id

    python -c "from core.license import LicenseManager; print(LicenseManager.get_machine_id())"

输出示例：a3f1b2c9d4e5f6a7b8c9d0e1f2a3b4c5

## 3. 签发 License

### 交互式签发
    python tools/license_generator.py

### 命令行签发
    python tools/license_generator.py --mid <machine_id> --licensee "公司名称" --expires 2099-12-31 --features all --output license.dat

## 4. 部署 License

将 license.dat 复制到目标机器的：
- Windows: %USERPROFILE%\.qa_tool\license.dat
- Linux/Mac: ~/.qa_tool/license.dat

## 5. 验证 License

    python -c "from core.license import LicenseManager; print(LicenseManager().verify())"

输出：LicenseStatus.VALID

## License 文件格式

    {
      "payload": {
        "mid": "a3f1b2c9d4e5f6a7b8c9d0e1f2a3b4c5",
        "product": "QA-Tool",
        "licensee": "公司名称",
        "issued_at": "2026-08-26T00:00:00Z",
        "expires_at": "2099-12-31T23:59:59Z",
        "features": ["all"]
      },
      "signature": "base64url(Ed25519签名)"
    }

## 安全说明

1. 私钥保密 — 私钥仅存储在开发者机器，不提交到 git
2. 公钥内置 — 公钥硬编码在 core/license_keys.py，无法被篡改
3. 硬件绑定 — License 绑定特定机器的 CPU+主板+磁盘+MAC
4. 离线验证 — 所有验证在本地完成，无需联网
5. 反调试保护 — 67 个检查点防止动态分析
6. 完整性校验 — 关键文件 SHA-256 校验防篡改
